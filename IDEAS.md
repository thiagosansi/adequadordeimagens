## Product Vision

**In one sentence:** Upload an image and get it automatically adjusted to any Meta Ads format — correctly cropped, never distorted, ready to publish.

**Problem:** Business owners without technical knowledge waste time manually resizing images for Meta Ads campaigns, often producing distorted or incorrectly sized creatives that underperform or get rejected.

**Main user:** Business owner without technical knowledge, running their own Meta Ads campaigns.
**Secondary user:** Traffic manager / marketing agency (potential future audience if turned into a product).

**Differentiator:** Enforces Meta Ads specs with real-time validation + zero distortion guarantee (crop or fit+background modes), all in the browser with no account or database required.

## Approved Feature Map

### CORE
- **Upload de imagem:** Drag & drop or button, accepts JPG/PNG/WebP
- **Seleção de formato Meta:** All official formats with visual preview of dimensions
- **Ajuste automático com crop:** Resizes and center-crops without distortion
- **Fit + background mode:** Entire image preserved inside frame, empty borders filled with solid color or blurred background
- **Recorte interativo:** User drags to define the crop area on the target format
- **Download da imagem ajustada:** JPG/PNG at exact target dimensions

### ESSENTIAL
- **Checklist de requisitos Meta:** Real-time validation — file size (< 30 MB), minimum resolution (600×600 px), exact ratio, accepted file format, safe zones for Stories/Reels
- **Aviso de texto excessivo:** Detects heavy text coverage and warns about the 20% rule
- **Preview antes/depois:** Side-by-side or toggle view of original vs adjusted
- **Exportar múltiplos formatos (.zip):** Select multiple formats and download all at once
- **Compressão automática:** Reduces file size while respecting the 30 MB limit without visible quality loss

### EXTENSION
- **Histórico de sessão:** List of images processed during current session (cleared on close)
- **Sugestão de formato:** Analyzes original ratio and suggests the best Meta format
- **Guia de requisitos Meta:** Reference screen with full updated specs table per campaign type
- **Marca d'água / branding:** Add logo to corner before export

### Dependencies
- Interactive crop depends on Upload
- Requirements checklist depends on Format selection
- Batch export depends on Auto adjustment

## Meta Ads Formats Reference

| Format | Dimensions | Ratio | Use |
|--------|-----------|-------|-----|
| Feed Square | 1080×1080 px | 1:1 | Feed / Carousel |
| Feed Portrait | 1080×1350 px | 4:5 | Feed (max vertical) |
| Feed Landscape | 1200×628 px | 1.91:1 | Feed / Link ads |
| Stories / Reels | 1080×1920 px | 9:16 | Stories, Reels |
| Collection | 1080×1080 px | 1:1 | Collection ads |

**Universal requirements:**
- Max file size: 30 MB
- Min resolution: 600×600 px
- Accepted formats: JPG, PNG
- Color space: RGB
- Safe zone Stories/Reels: top and bottom 14% reserved for UI elements
